# Code of conduct

We want Valley Roads to be welcoming to everyone. Be respectful and considerate, welcome different experience levels, give constructive feedback, and respect people's privacy. Harassment, discrimination, threats, personal attacks, and publishing private information without consent are unacceptable.

These expectations apply to project spaces and when representing the project. Maintainers may remove content, close discussions, or restrict participation when necessary.

To report a conduct concern, use [GitHub’s reporting tools](https://github.com/contact/report-abuse) for a private report to GitHub, or open an issue if it is appropriate to discuss the concern publicly. Include relevant links and context where possible.
