# Security policy

## Supported versions

Security fixes are considered for the latest code on the `main` branch. Older versions are not actively maintained.

## Reporting a vulnerability

Please do not report suspected security vulnerabilities in public issues. Use [GitHub's private vulnerability reporting](https://github.com/markldn/valley-roads/security/advisories/new) to send a report to the maintainers. Include steps to reproduce, the affected version or commit, and any relevant impact. Avoid accessing other people's data or disrupting the service while investigating.

The maintainer will review reports as availability permits and can coordinate a fix and disclosure with you through the private report.
